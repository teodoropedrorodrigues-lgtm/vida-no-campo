# 🌿 Blog Vida no Campo

Blog responsivo sobre agricultura, tecnologia rural e fazendas com estilização em tons de verde.

## 🚀 Como publicar no GitHub Pages:
1. Faça o commit desses arquivos na branch `main`.
2. Vá em **Settings** > **Pages** no repositório do GitHub.
3. Escolha a fonte `Deploy from a branch` e selecione a branch `main`.
4. Clique em **Save**.
